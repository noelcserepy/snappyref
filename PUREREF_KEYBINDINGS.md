# PureRef Keybindings Reference

These are kept as reference only. They are not the app's implemented shortcut list.

## Actions

- Align bottom: `Ctrl+Down` / `Cmd+Down`
- Align left: `Ctrl+Left` / `Cmd+Left`
- Align right: `Ctrl+Right` / `Cmd+Right`
- Align top: `Ctrl+Up` / `Cmd+Up`
- Arrange by name: `Ctrl+Alt+N` / `Opt+Cmd+N`
- Duplicate: `Ctrl+D` / `Cmd+D`
- Toggle drawer: `Ctrl+B` / `Cmd+B`
- Save: `Ctrl+S` / `Cmd+S`
- Undo crop: `Ctrl+Z` / `Cmd+Z`

## Controls

- Delete: `Delete` / `Backspace`
- Crop image: `C + Drag`
- Edit item: `Return`
- Focus canvas: `Ctrl+Space` / `Cmd+Space`
- Focus image: `Space`
- Pan: `Left Mouse + Alt` / `Left Mouse + Opt`
- Select all: `Ctrl+A` / `Cmd+A`
- Select items: `Left Mouse`
- Zoom in: `Ctrl++` / `Cmd++`
- Zoom out: `Ctrl+-` / `Cmd+-`

## Draw

- Draw arrow: `A + Drag`
- Draw line: `L + Drag`
- Draw textbox: `T + Click/Drag`

## Group

- Group: `Ctrl+G` / `Cmd+G`
- Ungroup: `Ctrl+Shift+G` / `Shift+Cmd+G`

## Multi Note

- Toggle bold text
- Toggle italic text
- Toggle text underline
- Text highlight color
- Paste text formatting

## Note

- Align text left: `Ctrl+Shift+L` / `Shift+Cmd+L`
- Align text center: `Ctrl+Shift+E` / `Shift+Cmd+E`
- Align text right: `Ctrl+Shift+R` / `Shift+Cmd+R`
- Decrease font size: `Ctrl+Shift+,` / `Shift+Cmd+,`
- Increase font size: `Ctrl+Shift+.` / `Shift+Cmd+.`
- Insert link: `Ctrl+K` / `Cmd+K`
- Paste without formatting: `Ctrl+Shift+V` / `Shift+Cmd+V`
- Toggle note auto size: `Ctrl+Shift+A` / `Shift+Cmd+A`
- Toggle bulleted list: `Ctrl+Shift+B` / `Shift+Cmd+B`
- Toggle numbered list: `Ctrl+Shift+N` / `Shift+Cmd+N`

- Next frame
- Play / Pause
- Previous frame

## System

- Move window: `Right Mouse`
- Resize window: `Left Mouse`
