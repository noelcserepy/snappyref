## Design Context

### Users
Professional artists in the game industry using the app as a design and reference tool for collecting, arranging, and navigating image references quickly. They are working in a production context where speed, clarity, and low interaction overhead matter more than decorative UI.

### Brand Personality
Direct, fast, simple.

The interface should feel calm, precise, and trustworthy. It should stay out of the way, reduce friction, and rely on sensible defaults so users can focus on visual work rather than interface management.

### Aesthetic Direction
Minimal, restrained, and layout-led rather than panel-heavy or feature-heavy. The product should not resemble a cluttered design tool full of boxes, controls, panels, or decorative chrome. It should feel like a professional instrument: quiet, immediate, and confident.

### Design Principles
1. Get out of the way. Favor direct manipulation, clear shortcuts, and minimal persistent UI.
2. Optimize for speed. Core actions should feel almost instant and avoid extra confirmation or setup.
3. Use layout before chrome. Prefer spacing, alignment, and hierarchy over borders, cards, and nested containers.
4. Keep defaults smart. Repeated decisions should be automated when reasonable so the user can stay in flow.
5. Preserve calm precision. Dense is acceptable; clutter is not. Every visible element should justify its existence.
